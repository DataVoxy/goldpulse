# DataVoxy Product Roadmap

## Company Groups

### 1. Financial Data & Trading Tools (LIVE)
- GoldPulse — gold market dashboard + signals
- SilverPulse — silver market dashboard + signals
- CryptoPulse — BTC/ETH dashboard + signals
- Future: MetalDeals (physical gold/silver price comparison)

### 2. Music, Neuroscience & Education
- EarTraining app (interval recognition with song references)
- Language pronunciation training (tone languages)
- Speech/auditory therapy tools (autism/ADHD)
- Spaced repetition + neuroscience-backed learning
- See: eartraining_ideas.md for detailed plan

### 3. Productivity Tools
- PDF editor/signer (free tier, premium for batch)
- Document tools (merge, compress, convert)
- Potential: note-taking, task management

### 4. Data & Analytics Consultancy
- Showcase platform demonstrating Azure/AWS/Python skills
- Portfolio of projects (scrapers, dashboards, pipelines)
- Freelance/contract work via DataVoxy brand
- Target: companies needing data engineering/analytics

### 5. AI Generation Tools
- Text/content generation tools
- Image generation wrappers
- AI-powered summaries/analysis
- Potential: AI writing assistant, code generator, data insights

---

## Priority Order
1. NOW: Market existing financial tools (2 weeks)
2. NEXT: Build ear training MVP (week 3-4)
3. LATER: Consultancy portfolio page
4. MAYBE: Productivity tools (only if clear demand)

## Key Principle
- Each group = separate audience, can share datavoxy.com domain (subdomains)
- Don't build all at once — ship one, validate, then next
- Edge is in group 2 (conservatory + coding) and group 4 (professional skills)
